What the intake should make explicit

01

Required views

Ask for the exact angles needed for this type of job, not an open-ended photo upload.

02

Scale and context

Capture dimensions, location and the customer’s intended outcome beside the images.

03

Access constraints

Surface height, entry, utilities and other constraints before scheduling a visit.

04

Review state

Show what is still missing and mark the request ready only when the minimum evidence is present.
